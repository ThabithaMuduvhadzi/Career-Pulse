# Career Pulse

Career Pulse is a web-based Job Application Tracking System designed to help students, graduates, and job seekers manage and monitor their job applications in one centralized platform.

## Features

- Job Application Tracking
- User Profile Management
- Dashboard Analytics
- Report Generation
- Application Statistics
- Multi-Factor Authentication (MFA)
- Password Reset Functionality
- SQLite Database Integration

## Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- MySwl

## Repository Structure

This project is provided as a ZIP archive to preserve the original folder structure required for the application to run correctly.

After cloning or downloading this repository:

1. Extract the ZIP file.
2. Place the extracted project folder in your web server directory (e.g., `htdocs` for XAMPP).
3. Start Apache.
4. Ensure the SQLite database file is present in the project directory.
5. Open the application in your browser.

http://localhost/Career-Pulse
